# Car Shop Database Design Project

A database design project for an **Car & Motor shop website** developed using **Microsoft SQL Server**. The project is divided into two phases: designing the database model and implementing it with SQL Server.

---

## Project Overview

This project demonstrates the complete process of designing and implementing a relational database for an car shop site. It covers conceptual database modeling, normalization, table creation, relationships, constraints, and stored procedures for common business operations.

---

## Technologies Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Visual Paradigm
- T-SQL

---

# Phase 1 — Database Design

The first phase focuses on designing the database structure before implementation.

### Objectives

- Analyze the requirements of an e-commerce system
- Identify entities and their relationships
- Design the Entity-Relationship (ER) Diagram
- Normalize the database
- Prepare the relational schema

### Deliverables

- ER Diagram (Visual Paradigm)
- Relational Schema
- Normalized Database Design

---

# Phase 2 — Database Implementation

The second phase implements the designed database using Microsoft SQL Server.

### Features

- Database Creation
- Table Creation
- Primary Keys
- Foreign Keys
- Constraints
- Indexes
- Stored Procedures

### Stored Procedures

Examples include:

- Insert Car Ad
- List and Delete Ads
- Query on Cars based on State & Body condition
- Delete the least seen Ad
- Filter Motors
- Max and Min in price estimation for a car
- Changing car colors


---

## Database Entities

Example entities include:
